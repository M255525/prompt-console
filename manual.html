操作手冊

提示詞控制台是依 CRISPE 架構設計的互動式提示詞產生器，把六個維度變成六個可填寫的模組，即時接成一份結構完整的提示詞。

什麼是 CRISPE 架構

C
Capacity 能力設定

你為 AI 設定的知識背景與能力範圍——它「懂什麼」。這是整份提示詞的能力上限，之後的角色、任務都在這個範圍內發揮。

R
Role 角色定位

在能力範圍內，更精確地定義 AI 這次要扮演的具體身份——它「是誰」。

I
Insight 背景洞悉

你提供給 AI 的背景資訊與情境脈絡——它需要「知道什麼」才能給出貼合實際的答案。

S
Statement 任務表述

你希望 AI 執行的具體任務——它要「做什麼」。這是整份提示詞的核心指令。

P
Personality 語氣人格

你期望輸出內容的風格或語氣——它要「怎麼說」。

E
Experiment 規則實驗

你對輸出內容的限制條件或規則設定——它「不能怎樣」。字數、格式、禁用詞都放在這裡。

操作步驟

  1. 先套用一個「範例」快速看懂每個模組該填什麼，或直接從空白開始；也可以用最上方的「AI 產生六個模組」，打一句話讓 AI 幫你草擬（見下方說明）
  2. 依序填寫六個模組；不需要每個都填，但填得越完整，AI 理解任務的偏差就越小
  3. 模組左側的圓形指示燈會在該模組有內容時亮起，代表訊號已接上
  4. 右下角「輸出訊號」模組會即時組成完整提示詞；可切換「標籤版」（保留六個標籤，方便自己檢查結構）或「精簡版」（去掉標籤的自然段落，貼給 AI 時較簡潔）
  5. 按「複製提示詞」貼到 ChatGPT、Claude、Gemini 等任何對話框
建議先用「語氣人格」模組下方的快速選項試試看——點一下就能把常用語氣加進欄位，不用自己打字。

已儲存的提示詞

最下方「已儲存的提示詞」是一個留在瀏覽器裡的紀錄清單，按「儲存」不會下載任何檔案，只是把目前六個模組的內容存成一筆有名字的紀錄，方便之後回來繼續編輯。

  1. 在儲存名稱欄位打一個好記的名字（留白會用「任務表述」內容自動取名），按「儲存」
  2. 清單中每一筆紀錄可以「載入」（覆蓋回六個模組繼續編輯）、「複製」（複製那筆內容不動目前欄位）、「下載 .txt」（把那一筆單獨存成檔案）、「重新命名」或「刪除」
  3. 取相同名字再按一次「儲存」會詢問是否要覆蓋既有紀錄
「儲存」＝存進這台瀏覽器的清單；「下載 .txt」才會真的產生一個檔案到你的下載資料夾。兩者是分開的動作。

AI 一句話產生六個模組（選用，需自備 API 金鑰）

頁面最上方的「一句話生成六模組」是選用功能：打一句你想做什麼，AI 會幫你把它拆解、擴寫成完整的 CRISPE 六個欄位，之後你還是可以逐一微調。

  1. 展開「API 連線設定」，選擇服務商（Claude／OpenAI／Gemini／OpenRouter），填入你自己申請的 API 金鑰；模型欄有預設值，也可以自行改成你想用的模型 ID
  2. 在上方欄位打一句需求描述，或點下方的快速範例
  3. 按「AI 產生六個模組」，確認彈出的提示後送出——若六個模組已有內容，會先自動備份，再被 AI 產生的內容覆蓋
  4. 不滿意可以按「還原 AI 產生前內容」復原成呼叫前的狀態
API 金鑰要自己到各服務商網站申請，使用時依你與該服務商的方案計費，本工具不會向你收費，也不會經手你的金鑰——金鑰只存在你這台電腦的瀏覽器，且直接連到服務商官方 API，不會經過本工具以外的任何伺服器。

什麼時候不需要填滿六格

CRISPE 是輔助思考的框架，不是必填表單。簡單任務（例如「幫我翻譯這句話」）通常只需要 Statement，硬湊其他欄位反而讓提示詞變得囉唆。欄位越多、內容越具體，通常適合用在需要 AI 扮演特定角色、輸出格式要求明確的任務上。

隱私說明

  • 你填寫的內容與「已儲存的提示詞」清單都只存在自己瀏覽器的 localStorage，關閉分頁後下次打開仍會保留，但不會傳送到任何伺服器；換一台電腦或清除瀏覽器資料就會不見，請自行用「下載 .txt」備份重要內容
  • 複製或下載提示詞後，貼到哪個 AI 服務、該服務如何處理這些文字，就依該服務自己的隱私政策規範，與本工具無關
  • API 金鑰同樣只存在瀏覽器的 localStorage；按下「AI 產生」時，你的一句話需求會直接連線送到你選擇的服務商官方 API，不會經過本工具作者或任何第三方伺服器
  • 「清空全部」會清除瀏覽器裡儲存的內容，此動作無法復原

使用警語

請注意：
  • 本工具的核心功能是把你的想法組織成結構化提示詞；只有你主動填入 API 金鑰並按下「AI 產生」時才會呼叫語言模型，不使用這項功能就完全不會連網，也不保證 AI 一定會給出你要的結果
  • 請勿在任何欄位輸入真實個資、公司機密、他人受著作權保護的內容，或不希望被 AI 服務留存的敏感資訊
  • AI 的回覆可能包含錯誤或過時資訊，使用前務必自行查證，特別是涉及法律、財務、醫療等專業判斷的情境
  • 使用「AI 產生」功能所產生的 API 費用由你與所選服務商的方案自行負擔，本工具不會向你收費
  • 本工具與創作者不對使用產生提示詞後所得之任何 AI 輸出結果負責
