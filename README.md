# 提示詞控制台

依 CRISPE 架構設計的互動式提示詞產生器，視覺主題為類比合成器控制台（modular synth patch bay）。純前端實作，無需安裝，開啟即玩。

**線上使用**：<https://m255525.github.io/prompt-console/>

---

## 快速開始

直接用瀏覽器開啟 `index.html`，即可開始使用。無需伺服器、無需安裝任何套件（頂部跑馬燈公告與「AI 產生」功能需要網路，其餘功能離線可用）。

---

## 這是什麼？

CRISPE 的六個維度是六個可填寫的「模組」，垂直排列如機架（rack），逐一填入後，最下方的「輸出訊號」模組會即時把它們組成一份結構完整、AI 看得懂的提示詞。左側一條訊號線貫穿所有模組，模組有內容時左側 LED 指示燈會亮起，象徵訊號已接上。

| 代號 | 名稱 | 說明 |
|------|------|------|
| C | Capacity 能力設定 | AI 該具備什麼樣的知識背景、專業程度 |
| R | Role 角色定位 | AI 這次要以什麼具體身份說話、做事 |
| I | Insight 背景洞悉 | AI 需要知道哪些背景資訊、限制條件或目標對象 |
| S | Statement 任務表述 | 明確說出要 AI 執行的具體任務 |
| P | Personality 語氣人格 | 希望輸出的語氣、風格 |
| E | Experiment 規則實驗 | 格式規則、字數限制或不希望出現的內容 |

---

## 功能

- **即時組成提示詞**：只組合非空欄位，「標籤版」（保留【中文標籤】方便檢查結構）與「精簡版」（去標籤的自然段落）可切換，一鍵複製
- **內建 4 組情境範例**：社群行銷文案顧問、電商客服回覆、課程教學助理、履歷潤稿顧問（皆為虛構情境）
- **AI 一句話產生六模組（選用）**：自備 API 金鑰，可串接 Claude／OpenAI／Gemini／OpenRouter，說一句需求由 AI 拆解填入六個模組，填好仍可自行微調；金鑰只存在瀏覽器本機，不經過任何中介伺服器
- **已儲存的提示詞**：存成有名字的紀錄留在瀏覽器裡（`localStorage`），之後可隨時載回繼續編輯；需要檔案再從清單個別下載 `.txt`

## 加入主畫面

右上角按「📲 加入主畫面」，可把工具安裝到手機或電腦桌面，之後不需開瀏覽器輸網址即可直接開啟。Android／桌面 Chrome 會直接跳出安裝視窗；iOS Safari 需透過「分享」→「加入主畫面」；Mac 桌面版 Safari 需透過「檔案」→「加入 Dock」。

---

## 隱私與安全

- 無伺服器端、無任何資料上傳；所有輸入只存在使用者瀏覽器的 `localStorage`
- 「AI 產生」功能需自行填入 API 金鑰，該金鑰只存在瀏覽器本機，按下產生時直接連線到你選擇的服務商官方 API，不經過本工具作者或任何第三方伺服器
- 請勿在任何欄位輸入真實個資、機密資料或受著作權保護的他人內容

## 響應式版面（RWD）

已在 320px（iPhone SE 等窄螢幕）到桌機寬度間實測，單欄卡片式版面搭配大量 `flex-wrap`，不會產生水平捲動。

## 技術規格

- 純 HTML / CSS / JavaScript，單一檔案（`index.html`），無框架、無建置步驟
- 支援 PWA 加入主畫面（`manifest.json` + `service-worker.js`）
- 相容 Chrome、Edge、Firefox、Safari 等主流瀏覽器
- 另有可攜式桌面版 exe（`Prompt_Eng/`）
