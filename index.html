提示詞控制台
操作手冊
C · R · I · S · P · E　FRAMEWORK

把一句模糊的要求，
接成一組精準指令

依 CRISPE 架構逐一填入六個模組，控制台會即時把它們接成一份結構完整、AI 看得懂的提示詞。

AI
Input Source 一句話生成六模組

串接你自己的語言模型 API，說一句你想做什麼，AI 會依 CRISPE 架構自動拆解、填入下方六個模組——填好之後仍可自行微調。

API 連線設定

金鑰只存在這台電腦的瀏覽器（localStorage），不會送到本工具以外的任何地方；按下「AI 產生」時，你輸入的一句話需求會直接傳送給你選擇的服務商 API。請勿在共用電腦上填寫金鑰。

C
Capacity 能力設定

你希望 AI 具備什麼樣的知識背景、專業程度或經驗？這是整個提示詞的能力上限。

R
Role 角色定位

在上面設定的能力範圍內，AI 這次要以什麼具體身份說話、做事？

I
Insight 背景洞悉

AI 需要知道哪些背景資訊、限制條件或目標對象，才能給出貼合實際狀況的答案？

S
Statement 任務表述

明確說出你要 AI 執行的具體任務，這是整份提示詞的核心指令。

P
Personality 語氣人格

希望輸出的語氣、風格是什麼樣子？可直接點選下方快速選項。

E
Experiment 規則實驗

有哪些格式規則、字數限制，或明確不希望出現的內容？

▶
Output 輸出訊號
0 / 6 模組已連接　·　0 字
REC
Saved Bank 已儲存的提示詞

把目前六個模組存成一筆有名字的紀錄，留在這台瀏覽器裡，之後隨時可以載回來繼續編輯；需要檔案再從清單裡個別下載。

使用警語
  • 本工具產生的是「提示詞架構」，不是最終答案；請自行檢查產生內容是否符合你所使用之 AI 服務的條款與政策。
  • 請勿在任何欄位輸入真實個資、機密資料或受著作權保護的他人內容——資料只存在你自己瀏覽器的 localStorage，不會上傳到任何伺服器，但貼上 AI 服務後的隱私仍由該服務條款規範。
  • 「AI 產生六個模組」需要你自行填入 API 金鑰，該金鑰只存在你的瀏覽器，按下產生時會直接連線到你選擇的服務商，本工具不會經手或保存金鑰，也不會向你收取任何 API 費用——實際費用依你與該服務商的方案計算。
  • AI 生成內容可能有誤，使用前請自行查證；本工具與創作者不對後續 AI 輸出結果負責。
  • 僅供教學、課程及個人使用，禁止未經授權公開發布、販售或商業化使用。
